# Clojure Monorepo Study Project

This repository contains multiple Clojure modules, each focused on a specific topic or concept in Clojure. Every module includes code and comments that highlight the main learning points for that topic.

## Modules Overview

- `calculo-imc`: Body Mass Index (IMC) calculator, covering namespaces, constants, function definitions, conditionals, and threading macros.
- `curso-clojure-iniciante`: Beginner Clojure course, focusing on `let` bindings, predicates, conditionals, and function documentation.
- `disciplinas`: Filtering and transforming vectors of maps, with emphasis on threading macros and function composition.
- `filter-map-reduce`: Practice with `filter`, `map`, and `reduce` for data processing.
- `funcoes-primeira-ordem`: First-class and higher-order functions, including anonymous and constant functions.
- `mais_sobre_vetores`: Vector manipulation, immutability, and the use of `assoc`.
- `mais-sobre-mapas`: Advanced map operations, including `assoc`, `dissoc`, `update`, and differences between lists and maps.
- `mapas`: Introduction to maps, nested structures, and idiomatic access patterns.
- `namespace_simbolos`: Namespaces, private/public functions, and predicate naming conventions.
- `self-testing-code`: Writing and testing functions with documentation and conditional logic.
- `tipos_clojure`: Exploration of Clojure's core data types and the `type` function.

Each module contains a README with a summary of the concepts learned.
