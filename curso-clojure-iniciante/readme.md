💻 Principais atalhos (default)
| Atalho                  | Ação                                              |
| ----------------------- | ------------------------------------------------- |
| `ctrl+alt+c ctrl+alt+j` | Conectar/Reiniciar o REPL (Jack-in)               |
| `ctrl+enter`            | Avaliar a forma (s-expression) atual              |
| `alt+enter`             | Avaliar a forma e exibir o resultado em linha     |
| `ctrl+alt+c ctrl+alt+s` | Conectar a REPL externa (Connect to running REPL) |
| `ctrl+alt+f`            | Format current form                               |
| `tab`                   | Autocomplete                                      |
| `ctrl+alt+t`            | Executar testes da namespace atual                |
| `ctrl+shift+space`      | Mostrar assinatura da função (signature help)     |
| `ctrl+u`                | Voltar (unwind) no REPL                           |
| `ctrl+l`                | Limpar output do REPL                             |
